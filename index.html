01

Sleep & GPA Predictor

A Streamlit application that estimates academic performance from sleep duration, schedule consistency, prior GPA, and student context.

  • Python
  • Streamlit
  • Scikit-learn
  • Seaborn
Live demo ↗ GitHub ↗
Project details +

My contribution

Machine learning engineering and frontend work across data cleaning, exploratory analysis, model training, evaluation, and Streamlit deployment.

Approach

Cleaned a 634-student dataset, handled missing values, and trained a Gradient Boosting Regressor using an 80/20 split and 5-fold cross-validation.

Results

MAE: 0.296 GPA points. R²: 0.256. User testing averaged 4.5/5 for usefulness and 4/5 for usability.

What we learned

Prior GPA was the strongest predictor. Sleep features still contributed meaningfully, while the model remained limited by dataset scope and omitted academic-context variables.

Computer Vision / Group Project

03

ASL Detection

A lightweight, real-time American Sign Language gesture detector built from hand landmarks rather than full-image processing.

  • Python
  • MediaPipe
  • SVC
  • Scikit-learn
Live demo ↗
Project details +

My contribution

Model training, performance troubleshooting, and runtime-quality improvements to keep real-time detection smooth and reliable.

Approach

MediaPipe extracts 21 hand landmarks as 63 coordinate features. An RBF-kernel Support Vector Classifier maps the normalized features to static ASL gestures.

Results

The best configuration—C=10 and gamma set to scale—reached 99.74% test accuracy, with most classes near 1.00 precision, recall, and F1.

Limitations

Landmark jitter, lighting, hand anatomy, and occlusion can affect predictions. Frame-by-frame classification does not yet model dynamic letters such as J and Z.

NLP / Group Project

04

Indonesian News Summarization

An abstractive summarization application that compares four transformer models on Indonesian news articles.

  • Transformers
  • XL-Sum
  • Streamlit
  • Hugging Face
Live demo ↗
Project details +

My contribution

Data processing, model training, evaluation, and engineering work across the end-to-end summarization pipeline.

Approach

Fine-tuned and compared T5, BART, mT5, and PEGASUS on Indonesian XL-Sum using 3,000 training, 500 validation, and 500 testing examples.

Results

BART led the comparison with a 22.75% ROUGE-1 score, followed by PEGASUS at 21.12%, mT5 at 17.35%, and T5 at 6.88%.

Limitations

Large models require significant compute, free deployment can be slow, and ROUGE alone cannot fully measure semantic quality.
