# Nihal Singh — Project Portfolio

A responsive portfolio featuring collaborative projects in machine learning, natural language processing, computer vision, and educational technology.

## Featured projects

- Sleep & GPA Predictor
- SummarEase
- ASL Detection
- Indonesian News Summarization

## Run locally

Open a terminal in this folder and run:

```bash
npm start
```

Then visit `http://localhost:5500`.

The site can also be served with any static file server.
